## 해결하는 문제

신제품, 콜라보, 시즌 KV에는 사람들이 멈춰서 들여다보는 이미지가 필요할 때가 많습니다. 평범한 상품 컷으로는 안 되고, 순수한 3D 만화풍은 상품을 알아볼 수 없게 만듭니다.

**Shop 008**은 작은 이야기를 들려줍니다. 도시 스케일로 커져 블록으로 지어진 상품이 미니어처 세계 한가운데 서 있고, 비계·크레인·정비 플랫폼이 둘러싸며, 블록 일꾼들이 나르고, 닦고, 문지르고, 붙이고, 점검합니다. 장면은 카테고리에서 확장됩니다. 음료라면 물류, 스킨케어라면 깨끗한 실험대.

## "레고 스타일"에 대해

이것은 조립 스타일이지 브랜드가 아닙니다. 실제 블록 브랜드의 로고와 워드마크는 스터드를 포함해 어디에도 나오지 않습니다. 일꾼은 정교하고 생동감 있는 미니어처 블록 인형으로, 확대해도 손과 얼굴이 또렷합니다.

## 준비할 것

- **상품 이미지**(필수): 패키지, 색, 로고, 글자 배치는 모두 사진에서 가져오며, 블록이 되어도 알아볼 수 있어야 합니다.
- **장면**(선택): "물류 창고", "실험대"처럼 생각한 장면이 있으면 말해 주세요.
- **행사 헤드라인**(선택): 상품을 가리지 않는 위치의 공사 안내판이 됩니다.

## 사용 방법

### 1단계: 설치 (한 번만)

```bash
git clone https://github.com/nevertoday/xxd-shop-008.git
mkdir -p ~/.claude/skills
ln -s "$(pwd)/xxd-shop-008" ~/.claude/skills/xxd-shop-008
```

Codex 사용자는 같은 폴더를 `~/.codex/skills/xxd-shop-008`에 링크하세요. 설치 후에는 AI 어시스턴트 세션을 다시 시작합니다.

### 2단계: 원하는 것을 평소 말로 말하기

```text
/xxd-shop-008 이 탄산수 캔으로 블록 공사장 포스터를 만들어 줘
/xxd-shop-008 이 텀블러로 9:16 한 장, 공사 안내판에 "신제품 건설 중 · 9월 20일 오픈"
/xxd-shop-008 이 원두 봉지로 서로 다른 공사 이야기 두 장
```

외울 플래그는 없습니다. 사이즈나 장수처럼 정하지 않은 것은 한 번에 모아서 묻고, 다음에는 지난 설정을 다시 쓸 수 있습니다.

### 3단계: 그다음에 하는 일

1. 상품 이미지와 설명을 읽고 아직 정해지지 않은 것만 묻습니다. 사이즈는 용도에 맞춰 픽셀 크기와 함께 추천합니다.
2. 이 스타일은 기본적으로 글자를 넣지 않고(글자는 상품 패키지에 있는 것뿐), 글자에 대해 묻지도 않습니다. 준 헤드라인은 공사 안내판이 됩니다.
3. 사이즈마다 새로 구도를 잡고, 다른 이미지에서 잘라내지 않습니다.
4. 납품 전에 한 장씩 확인합니다. 상품이 바뀌지 않았는지, 철자가 맞는지, 주지 않은 숫자가 있는지. 통과하지 못한 것은 알리고 다시 만듭니다.
5. PNG를 `~/Desktop/xxd/xxd-shop-008/` 아래 새 작업 폴더에 저장하고 경로를 알려 줍니다.

## 자주 묻는 질문

**가로형도 되나요?**

되지만 스타일은 세로 구도입니다. 가로형은 랜드마크 효과가 약해지므로 먼저 알려 드립니다.

**무엇이 필요한가요?**

세 가지입니다. ① Claude Code나 Codex처럼 Skills를 지원하는 AI 어시스턴트. ② 이미지를 생성할 수 있는 모델: 어시스턴트에 내장된 이미지 생성, 또는 Codex에 설정한 모델 제공자로 Responses API를 통해 이미지를 생성하는 것(기본 GPT Image 2). ③ Pillow가 설치된 Python 3.11 이상(`pip install pillow`).

**비용이 드나요? 상업적으로 써도 되나요?**

Skill은 무료로 내려받을 수 있고, 이미지 생성 비용은 본인의 모델 계정에 청구됩니다. 자기 상품·스토어·브랜드(직원으로서 다니는 회사 포함)의 이미지를 만드는 것은 신청 없이 상업적으로 써도 됩니다. Skill 재판매, 유료 서비스화, 다른 사람을 위한 유료 이미지 제작은 먼저 작성자의 서면 허가가 필요합니다. 맨 아래 "라이선스"를 참고하세요.

**이미지는 얼마나 큰가요?**

비율이나 정확한 픽셀을 요청할 수 있습니다. 실제 크기는 모델이 돌려준 그대로이며 몰래 업스케일하지 않고, 파일 이름에 실제 픽셀이 적힙니다.

**이미지 속 글자에 오타가 생기나요?**

AI 이미지는 가끔 철자를 틀리거나 브랜드 이름 옆에 ® 같은 작은 기호를 덧붙입니다. 납품 전에 한 장씩 확대해 확인하고, 통과하지 못하면 다시 만듭니다. 이 페이지의 예시는 모두 그 확인을 통과했습니다.

**가격이나 판매량을 지어내나요?**

아니요. 가격, 사양, 원산지, 판매량, 수상, 인증처럼 사실로 보이는 것은 내가 준 것이나 상품에서 또렷이 읽히는 글자에서만 가져옵니다. 그 밖에는 넣지 않으며 "¥XX" 자리표시도 없습니다.

**상품 여러 개를 한 번에 처리할 수 있나요?**

네. 상품 이미지 폴더를 주세요. 이미지 하나에 상품 하나, 사이즈와 글자는 한 번만 묻고, 한 상품의 사실이나 문구가 다른 상품으로 새지 않습니다.
